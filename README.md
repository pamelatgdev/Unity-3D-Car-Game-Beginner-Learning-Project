# Unity 3D Car Game
An educational 3D car game developed with Unity for the Augmented Reality course at UNESP during the second semester of 2024.

## About
This project was developed as an academic activity for the Augmented Reality course at UNESP. The game was created as a hands-on learning resource to introduce fundamental concepts of 3D game development using Unity.
Using a simple car game, the project explores Unity's core features, 3D object manipulation, scripting, physics, object hierarchy, cameras, and player interaction.

## Requirements
- Unity **2022.3.10f1**
Using the same Unity version is recommended to ensure compatibility with the project.

## How to Run
1. Clone or download this repository.
2. Open **Unity Hub**.
3. Click **Add** or **Open** and select the downloaded project folder.
4. Open the project using **Unity 2022.3.10f1**.
5. In the Unity Editor, open the main game scene included in the project.
6. Press the **Play** button to start the game.

## How to Play

### Controls
| Key | Action |
|---|---|
| `W` | Move forward |
| `S` | Move backward |
| `A` | Move left |
| `D` | Move right |
| `Space` | Jump |
| `1` | Switch to first-person camera |
| `3` | Switch to third-person camera |
| `R` | Reset the car's position and rotation |
| `P` | Restart the entire scene |

### Gameplay Features
- Keyboard-controlled vehicle movement
- Wheel rotation
- Jumping with physics
- First-person and third-person camera views
- Top-down minimap
- Physics-based objects
- Vehicle reset
- Scene restart
