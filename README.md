# Unity 3D Car Game
An educational 3D car game developed with Unity for the Augmented Reality course at UNESP during the second semester of 2024.

## About
This project was developed as an academic activity for the Augmented Reality course at UNESP. The game was created as a hands-on learning resource to introduce fundamental concepts of 3D game development using Unity.
Using a simple car game, the project explores Unity's core features, 3D object manipulation, scripting, physics, and player interaction.

## Learning Topics
- Unity Editor and project organization
- GameObjects and Components
- Transform (position, rotation, and scale)
- Object hierarchy
- Materials and textures
- C# scripting
- Start() and Update()
- Variables and Inspector parameters
- Keyboard input
- Object movement and rotation
- Time.deltaTime
- Rigidbody and physics
- Vehicle movement and wheel rotation
- First-person and third-person cameras
- Minimap
- Jumping and physics-based interaction
- Resetting objects and reloading scenes
